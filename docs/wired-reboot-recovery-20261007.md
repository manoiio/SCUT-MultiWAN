09:45 整机意外重启后，有线静态 IP 和 carrier 正常，持久会话账本仍保留旧 IP，但认证进程持续退出 75。新增安全阶段日志确认失败点是旧会话注销未获确认；中间的 76 来自原有 120 秒重试间隔保护。

旧实现仅发送组播 Logoff，每次只接收一帧、等待 0.5 秒。单纯增加广播和等待时间在本次真实重试中仍未获得回复。因此新增受全局 Portal 锁保护的发现与定向注销：

1. 先发组播/广播 Logoff，使用单调时钟和收包次数限制等待。
2. 尚未建立本进程会话且注销无确认时，仅发送一次不携带凭据的广播 EAPOL Start，获取交换机的 Identity 请求及地址。
3. 不调用 Identity/MD5 回复处理器，向该交换机定向 Logoff；只接受同一交换机的明确 EAP Failure 作为释放确认。
4. 确认后由原守卫更新会话账本，再进入正常登录。无回复、错误来源或畸形报文仍拒绝继续登录。
