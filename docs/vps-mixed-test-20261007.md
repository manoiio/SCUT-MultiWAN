## 地址族与项目调研

Linux MPTCP 允许 IPv4/IPv6 混合子流。初次客户端使用 `tcp6` 时只形成一个 IPv6 子流；改用双栈 `tcp`，服务器公告 IPv4、客户端 fullmesh 后，`ss` 确认一个有线 IPv6 与两个无线 IPv4。Go 源码增加可选 `transport_network: tcp`，默认仍为 `tcp4`；本地 race 检查通过。新实验二进制没有替换生产二进制。

原生 MPTCP 的路径配置见 [官方文档](https://www.mptcp.dev/pm.html) 与 [ip-mptcp 手册](https://man7.org/linux/man-pages/man8/ip-mptcp.8.html)。比较了 [OpenMPTCProuter](https://github.com/Ysurac/openmptcprouter/wiki)、[Glorytun](https://github.com/angt/glorytun)、[MLVPN](https://github.com/zehome/MLVPN)、[mqproxy](https://github.com/mp0rta/mqproxy) 和 [mqvpn](https://github.com/mp0rta/mqvpn)。本轮没有安装或部署这些项目。mqproxy 的单 TCP 经多路径 QUIC 聚合是后续候选，但发行二进制的 libc、OpenWrt 交叉构建、UDP 映射、认证与证书验证仍需实际核对；作者的实验成绩不能替代本机验收。
